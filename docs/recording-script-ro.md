# Romanian voice recording script

Every phrase the app says in Romanian. The app joins short pieces together
(e.g. **"Găsește litera"** + **"be"**), so many lines are only the start of a sentence.

**How to record**
- Quiet room with soft things around (curtains, sofa). Phone ~20 cm from your mouth.
- Cheerful, warm, a little slower than normal, as if talking to a 4-year-old.
- Say each line once, leave ~1 second of silence, then the next. Redo any you don't like.
- Save each clip with the **exact file name** in the table (any format: m4a, mp3, wav).
  Easiest: one long recording per section, and I cut it into files for you.
- Sentence starts ("Găsește litera…") end in a slightly rising, "unfinished" tone,
  because a letter, number or word follows right after.

Total: **196 clips**.
